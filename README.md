# 🚆 IRCTC Business Insights Dashboard | Power BI

## 📌 Project Overview

The **IRCTC Business Insights Dashboard** is an interactive data analytics project developed using Microsoft Power BI to analyze railway booking performance, revenue generation, passenger activity, train occupancy, and route-wise demand.

The dashboard transforms railway booking data into meaningful visual insights that support data-driven decision-making and help identify business performance trends.

-------

## 🎯 Project Objectives

- Analyze overall railway booking performance.
- Monitor total revenue and user activity.
- Identify the busiest routes based on booking volume.
- Analyze booking trends over time.
- Compare revenue by booking type and booking channel.
- Monitor average train occupancy.
- Present key business insights through an interactive dashboard.

-----

## 📊 Dashboard Highlights

### 1. Key Performance Indicators (KPIs)

The dashboard displays the following metrics:

- **Total Bookings:** 20K
- **Total Revenue:** 53M
- **Total Users:** 19K
- **Trains Operated:** 540
- **Average Occupancy:** 79.92

*Note: These figures represent the values displayed in the dashboard and should be interpreted according to the dataset's units and definitions.*

### 2. Booking Trend Analysis

- Visualizes monthly booking activity.
- Helps identify increases and decreases in booking volume.
- Supports analysis of seasonal demand patterns.

### 3. Revenue Analysis

- Compares revenue across booking types.
- Analyzes revenue generated through different booking channels.
- Helps identify high-performing booking categories.

### 4. Top Routes by Booking

The dashboard highlights the leading routes by booking volume, including:

- Delhi – Mumbai
- Delhi – Howrah
- Mumbai – Pune
- Bengaluru – Chennai
- Lucknow – Delhi

Delhi–Mumbai has the highest booking volume among the routes displayed in the current dashboard.

### 5. Key Business Insights

The dashboard helps users explore:

- Overall booking and revenue performance.
- Route-wise passenger demand.
- Booking channel performance.
- Monthly booking fluctuations.
- Average train occupancy and utilization.
